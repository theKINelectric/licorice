Read keys can recall, inspect and export this project. Write keys also add evidence and start sessions. Neither can manage accounts, projects or keys.

Set your key in an environment variable; keep it out of source control. Each request ID must be stable when retrying the same write.

Retention & deletion
Changing retention sets a deadline from now for the entire project, including all observations and history. This is not per-record expiry. Access stops at the deadline; background file cleanup runs every minute. Minimal deletion and revocation records remain to prevent restored access. Export first if you need a copy.


Account security & data
Security changes and account deletion require signing in within the last 10 minutes. Account sessions expire after 7 days. Exports contain evidence and history, without credentials. Keep your own export: this early-access service does not yet offer account restoration after total server loss.
